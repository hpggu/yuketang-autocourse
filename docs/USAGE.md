# 使用说明（v2.0，CDP 版）

## 一、它解决什么问题

雨课堂「学习空间」里，一节课下面常挂着十几个视频节点，每个 8～15 分钟。播完一个要手动点左侧目录里的下一个 —— 纯机械劳动。

本脚本替你按顺序点下去，播完一个自动进下一个，顺手跳过夹在中间的作业和讨论题。

它**只做**三件事：

1. 视频暂停了就恢复播放（包括被平台自己暂停、被 `NotAllowedError` 拦下的情况）
2. 视频播完后点目录里的下一个视频节点
3. 播放时间长时间不动时，重新确认状态并续播；同一节反复卡住就跳到下一节

## 二、环境要求

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11 |
| PowerShell | 5.1 及以上（系统自带即可） |
| 浏览器 | Microsoft Edge 或 Chrome（需要能开远程调试端口） |
| 网络 | 能正常打开雨课堂即可 |

不需要：油猴、Python、Node、任何安装包。

## 三、第一次使用

### 1. 准备页面

用浏览器打开雨课堂 → 进入「学习空间」→ 点进一门课 → **点开任意一个视频**。

确认两件事：

- 播放器已经加载出来（能看到播放按钮和 `1:30 / 10:34` 这样的时间）
- 左侧目录显示出来，当前节点是高亮的

### 2. 启动

双击 `启动刷课.cmd`。它会：

1. 探测 `http://127.0.0.1:9222/json/version` 是否可达；
2. 不可达时结束现有 Edge / Chrome，用 `--remote-debugging-port=9222 --restore-last-session` 重新启动（浏览器会自己恢复上次的标签页，登录态不丢）；
3. 等端口起来后启动 `AutoCourse.ps1`。

成功时黑窗口里会出现：

```
[14:10:52] 雨课堂自动连播 v2.0.0 启动（CDP 模式）
[14:10:52] 日志文件：...\src\logs\autocourse-20261115-141052.log
[14:10:52] 已连接页面：学习空间
[14:10:57] 已接管。停止：双击 停止自动连播.cmd，或本窗口按 Ctrl+C。
[14:10:57] 当前小节：视频 1.1 可视化初识
[14:10:57] 暂停中（1:11 / 10:34），尝试恢复播放。
[14:10:57] WARN play() 失败（NotAllowedError），改点播放器中央。
[14:10:58] 点击后开始播放。
```

之后每播完一节会打印：

```
[14:32:11] 本节播完（10:34 / 10:34），3 秒后切下一节。
[14:32:17] 点到下一节：视频 1.2 可视化的前世今生
```

### 3. 停止

- 双击 `停止自动连播.cmd`：会在项目目录写下 `STOP_AUTOCOURSE` 标记，脚本 2 秒内读到并退出
- 或直接在黑窗口里按 `Ctrl+C`

两种方式都会在退出时清理标记文件，下次启动不受影响。

## 四、运行期间的行为边界

脚本每 2 秒（`-PollSeconds`）在页面里执行一次极短的 JS，读四项东西：`currentTime`、`duration`、`paused`、当前高亮目录节点，外加一次浮层探测。

所以：

- **不抢鼠标、不抢键盘、不需要窗口在前台** —— 你可以最小化浏览器去做别的事
- 唯一代价是同浏览器里那个雨课堂标签页不能被关掉或跳到别的页面
- 脚本只有在你手动操作后（比如手动暂停）才会介入恢复
- 中断方式：`Ctrl+C` 会走 `finally`，释放互斥量并清理标记

## 五、命令行开关

```powershell
$PS = 'powershell -ExecutionPolicy Bypass -File .\src\AutoCourse.ps1'

# 只体检一次，不动页面
& $PS -Once

# 立即切到下一节视频
& $PS -NextNow

# 换端口
& $PS -Port 9333

# 标签页关键字换成多个平台的并集
& $PS -UrlMatch 'yuketang|gdufemooc'

# 放慢轮询，省资源
& $PS -PollSeconds 5

# 只放完 3 节就停
& $PS -MaxVideos 3
```

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `-Port` | `9222` | 浏览器远程调试端口 |
| `-PollSeconds` | `2` | 轮询间隔（秒） |
| `-Once` | — | 只打印一次状态就退出，不操作页面 |
| `-NextNow` | — | 立刻切到下一个视频节点 |
| `-UrlMatch` | `yuketang` | 选标签页用的 URL 正则 |
| `-MaxVideos` | `0` | 本次最多播放几节，`0` 表示不限制 |
| `-MaxStuckPerLesson` | `20` | 同一节卡住多少次后强制跳下一节 |
| `-MaxStuckTotal` | `60` | 全程累计卡住多少次后退出 |
| `-EndToleranceSeconds` | `1.5` | 距片尾多少秒算播完 |
| `-Quiet` | — | 只写日志，不打印到控制台 |

### `-Once` 的用途

它是排错第一工具。输出示例：

```
Version      : 2.0.0
Transport    : CDP / WebSocket (port 9222)
PageTitle    : 学习空间
PageUrl      : https://changjiang.yuketang.cn/ai-workspace/lms-graph/26433347/video/48332005?...
ActiveLeaf   : 视频 1.1 可视化初识
LeafCount    : 77
CurrentTime  : 1:30
Duration     : 10:34
IsPlaying    : True
IsComplete   : False
ReadyState   : 4
PlaybackRate : 1
VideoSize    : 1151x405
Overlays     : 0
```

判断方法：

| 现象 | 含义 |
| --- | --- |
| `VideoState : 没找到 <video>` | 标签页不是视频页，或播放器还没加载 |
| `LeafCount` 为 0 或明显变小 | 目录节点选择器 `.leaf-item` 变了 |
| `ActiveLeaf` 为空 | 当前节点没有 `is-active` 标记 |
| `Duration` 为 `--:--` | 视频元数据没加载完（`readyState < 1`） |
| `IsPlaying` 恒为 False 但画面在动 | 页面自己接管了播放，`video.paused` 不可信 |
| `Overlays` 不为 0 | 有浮层，看 `overlayPreview` 里是什么类名 |
| `PlaybackRate` 不是 1 | 平台或扩展改过倍速，本项目不改这个值 |

## 六、故障排查

### 「端口 9222 上没有可用的调试接口」

浏览器不是带调试端口启动的。用 `启动刷课.cmd`，或手动：

```
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --remote-debugging-port=9222 --restore-last-session
```

注意：**已经在运行的浏览器无法事后开启调试端口**，必须先彻底退出（任务管理器确认 `msedge.exe` 全部结束）。

### 「没有找到匹配 'yuketang' 的标签页」

端口通了但没开雨课堂页面。报错里会列出当前所有标签页 URL，照着开出来，或用 `-UrlMatch` 换关键字。

### 「当前页面还没有 `<video>` 元素，等播放器加载……」

正常会自动等到加载完。一直这样说明标签页停在目录页 / 作业页，手动点开一个视频。

### 「play() 失败（NotAllowedError）」

浏览器的自动播放策略拦住了。脚本会退回 CDP 点击播放器中央。如果还不行，手动点一次播放，之后脚本接手就不会再被拦。

### 播完一节卡住不动

看日志最后一行：

- 「没有找到后面的视频节点（no-next）」→ 已是最后一个视频，正常结束
- 「没有找到后面的视频节点（no-leaves）」→ 目录没渲染，选择器或页面状态有问题
- 「仍然没能恢复播放，可能是随堂测验挡住了播放器」→ 有浮层，需要手动处理
- 「本节卡住 N 次，强制切下一节」→ 本节推不动，脚本主动跳过
- 「累计卡住 N 次，放弃」→ 全程都不顺，退出码 1

### 弹题如何处理

脚本**不答题**。遇到随堂测验时，浮层会盖住播放器，`play()` 可能被拦、点击落在浮层上。手动答完关掉浮层，脚本会自己继续；不处理的话它会累计到 `MaxStuckPerLesson` 后跳过这一节。

## 七、日志

- 位置：`src\logs\autocourse-yyyyMMdd-HHmmss.log`
- 每次运行一个文件，控制台和文件内容一致（`-Quiet` 时只有文件）
- 提 issue 时请附完整日志和 `-Once` 输出

## 八、卸载

删掉整个文件夹即可。脚本不写注册表、不装服务、不驻留后台；唯一痕迹是项目目录内的 `logs\` 和运行期间临时的 `STOP_AUTOCOURSE`。

调试端口只是浏览器的一个启动参数，关掉浏览器就没了。

## 九、边界声明

- 只做「播放 / 切下一节」，不改倍速、不静音、不拖进度条
- 不伪造进度上报，不保证课程被平台记为「已完成」
- 不处理作业、讨论题、考试、签到
- 不绕过任何平台检测机制
- 请自行确认所在学校与课程是否允许自动播放
