# 使用说明

## 一、它解决什么问题

雨课堂「学习空间」里，一节课下面常挂着十几个视频节点，每个 8～15 分钟。播完一个要手动点左侧目录里的下一个 —— 这是纯粹的机械劳动。

本脚本替你按顺序点下去，播完一个自动进下一个，顺手跳过夹在中间的作业和讨论题。

它**只做**三件事：

1. 视频暂停了就点播放（包括被平台自己暂停的情况）
2. 视频播完后点目录里的下一个视频节点
3. 播放时间长时间不动时，重新确认播放状态并续播；同一节反复卡住就跳到下一节

## 二、环境要求

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11 |
| PowerShell | 5.1 及以上（系统自带即可） |
| 浏览器 | Microsoft Edge 或 Chrome（脚本按进程名识别，默认 `msedge, chrome`，其他浏览器用 `-ProcessName` 指定） |
| 显示缩放 | 建议 100%，非 100% 可能导致读不到时间文本 |
| 网络 | 能正常打开雨课堂即可 |

不需要：油猴、Python、Node、任何安装包。

## 三、第一次使用

### 1. 准备页面

用浏览器打开雨课堂 → 进入「学习空间」→ 点进一门课 → **点开任意一个视频**。

确认三件事：

- 播放器已经加载出来（能看到播放按钮和 `00:00 / 12:30` 这样的时间）
- 左侧目录显示出来了，当前节点是高亮的
- 页面**没有最小化**

### 2. 启动

双击 `src/启动自动连播.cmd`。

成功时黑窗口里会出现：

```
[13:46:48] 雨课堂自动连播 v1.1.0 启动
[13:46:48] 日志文件：...\src\logs\autocourse-20261115-134648.log
[13:46:48] 已锁定窗口：学习空间 - 雨课堂
[13:46:52] 自动连播已启动，保持该标签页打开；停止请双击 停止自动连播.cmd 或按 Ctrl+C。
```

之后每播完一节会打印：

```
[14:02:11] 本节播放结束：12:30 / 12:30
[14:02:11] 等待平台保存进度...
[14:02:14] 打开下一个视频节点：第 2 节 变量与作用域 视频
[14:02:16] 进入新节点：第 2 节 变量与作用域 视频
```

### 3. 停止

- 双击 `src/停止自动连播.cmd`，窗口会在 2 秒内打印「收到停止请求，退出。」并退出
- 或者直接在黑窗口里按 `Ctrl+C`

两种方式都会清掉 `STOP_AUTOCOURSE` 标记文件，下次启动不受影响。

## 四、运行期间的行为边界

脚本运行时会周期性地（默认每 2 秒）：

- 用 `CacheRequest` 把整棵无障碍树缓存下来读一次
- 判断是否在播放、是否播完
- 需要时把鼠标移到播放器底部约 0.9 秒，让控制条浮出来读时间，**然后还原鼠标位置**

所以：

- 这几百毫秒内如果你在精确操作鼠标，可能被抢一下 —— 别在跑脚本时做需要精准点击的事
- 脚本会主动把浏览器窗口提到前台一次（启动时），之后不再抢焦点
- 浏览器窗口可以被别的窗口挡住，但**不能最小化**，最小化后无障碍树不完整
- 兜底鼠标点击前会校验「前台窗口是不是目标窗口」「点击坐标有没有被遮挡」，不满足就跳过并写日志

## 五、命令行开关

```powershell
$PS = 'powershell -ExecutionPolicy Bypass -File .\src\AutoCourse.ps1'

# 只体检一次，不动页面
& $PS -Once

# 立即切到下一节视频
& $PS -NextNow

# 放慢轮询，省 CPU
& $PS -PollSeconds 5

# 只放完 3 节就停
& $PS -MaxVideos 3

# 指定浏览器
& $PS -ProcessName chrome
```

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `-PollSeconds` | `2` | 轮询间隔（秒），最小 1 |
| `-Once` | — | 只打印一次状态就退出，不操作页面 |
| `-NextNow` | — | 立刻切到下一个视频节点 |
| `-ProcessName` | `msedge, chrome` | 目标浏览器进程名，可传多个 |
| `-MaxVideos` | `0` | 本次最多播放几节，`0` 表示不限制 |
| `-MaxStuckPerLesson` | `20` | 同一节卡住多少次后尝试跳到下一节 |
| `-MaxStuckTotal` | `60` | 全程卡住多少次后退出 |

### `-Once` 的用途

它是排错第一工具。输出示例：

```
Version      : 1.1.0
WindowTitle  : 学习空间 - 雨课堂
PlayerClass  : xt_video_player
LessonCount  : 12
VideoCount   : 8
ActiveLesson : 第 3 章 数组与对象 视频
CurrentTime  : 04:12
Duration     : 12:30
IsPlaying    : True
IsComplete   : False
```

判断方法：

| 现象 | 含义 |
| --- | --- |
| `CurrentTime` 为空 | 时间文本没读到 → 缩放比例、遮挡、或类名变了 |
| `ActiveLesson` 为空 | 目录节点没识别 → `leaf-item` 类名变了 |
| `LessonCount` 为 0 | 左侧目录没展开，或 `leaf-item` 类名变了 |
| `VideoCount` 为 0 | 目录里没有带「视频」标签的节点 → 标签文案改了 |
| `IsPlaying` 恒为 False 但视频在播 | 播放按钮类名变了 |
| 直接报「窗口中未识别到播放器」 | 播放器类名 `xt_video_player` 不匹配了 |

## 六、故障排查

### 「未找到包含播放器的浏览器窗口」

没找到含播放器的窗口。按顺序确认：

1. 用的是 Edge 或 Chrome，其他浏览器要用 `-ProcessName` 指定进程名
2. 视频页确实打开了，播放器加载完了
3. 浏览器没被最小化
4. 只有一个窗口开着雨课堂（多窗口会取错）

### 「窗口中未识别到播放器，可能页面还没加载完」

窗口对了但播放器还没渲染。等 5 秒再来一次，或先手动点一下播放让播放器激活。

### 一直打印「还没识别到播放器，等待页面加载。」

页面在跳转。正常会在几秒内恢复。持续超过 1 分钟，说明类名变了，用 `-Once` 确认。

### 播完一节卡住不动

看日志最后一行：

- 「未找到当前高亮的课程节点」→ 目录里当前节点没有 `is-active` 标记
- 「后面已经没有可播放的视频节点了」→ 已经是最后一个视频，正常结束
- 「视频处于暂停，但播放按钮不可点」→ 播放按钮被浮层挡住（弹题、公告）
- 「播放时间停在片尾不再推进，按已看完处理」→ 片尾兜底生效，属正常
- 「本节反复卡住，尝试跳到下一节」→ 本节确实推不动，脚本主动跳过

### 播放时间长时间不变

平台可能弹了题目或公告挡住播放器。脚本只会尝试续播、累计计数、必要时跳节，**不会**帮你答题 —— 手动处理完遮挡它会自己继续。

## 七、日志

- 位置：`src\logs\autocourse-yyyyMMdd-HHmmss.log`
- 每次运行一个文件，控制台和文件内容一致
- 提 issue 时请附上完整日志和 `-Once` 输出

## 八、卸载

删掉整个文件夹即可。脚本不写注册表、不装服务、不驻留后台，唯一的外部痕迹是运行时生成的 `logs/` 和临时出现的 `STOP_AUTOCOURSE` 文件，都在项目目录内。

## 九、边界声明

- 只做「播放 / 切下一节」，不改倍速、不静音、不拖进度条
- 不伪造进度上报，不保证课程被平台记为「已完成」
- 不处理作业、讨论题、考试、签到
- 不绕过任何平台检测机制
- 请自行确认所在学校与课程是否允许自动播放
